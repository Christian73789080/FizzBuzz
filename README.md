# Algoritmo FizzBuzz

## Objetivo
Receber um número inteiro N e imprimir os números de 1 até N, seguindo as regras:
- FizzBuzz: múltiplo de 3 e 5;
- Fizz: múltiplo de 3;
- Buzz: múltiplo de 5;
- Caso contrário: imprimir o próprio número.

## Como executar
1. Tenha o Java instalado.
2. Abra o terminal na pasta deste arquivo.
3. Compile:
   ```bash
   javac FizzBuzz.java
   ```
4. Execute:
   ```bash
   java FizzBuzz
   ```
5. Digite o valor de N quando solicitado.

## Exemplo
Para N = 15, a saída termina com:
```text
13
14
FizzBuzz
```
